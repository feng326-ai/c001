## 安全边界

- 审核写事务先调用固定 `search_path`、PUBLIC 无 EXECUTE 的 `app_authorize_tenant_write(integer,uuid)`，锁定 enabled user、active tenant、active membership；撤权形成事务屏障。
- Grant 是控制面只读表。runtime 不获得 UPDATE，而是调用第二个窄函数 `app_lock_active_review_grant(uuid,uuid)` 锁定当前租户的一条有效授权。
- runtime 对身份、共享情报和 Grant 仅 SELECT；Candidate 仅 SELECT/UPDATE；Review 和命令账本仅 SELECT/INSERT/UPDATE；Outbox 仅 SELECT/INSERT；所有 DELETE/TRUNCATE/REFERENCES/TRIGGER 均拒绝。
- Grant、Candidate、Review、Outbox、命令账本全部 `ENABLE/FORCE RLS`。跨租户 UUID 与不存在对象统一不暴露。
- 普通候选读取可以使用请求快照；高价值写入使用严格授权锁。事务不得跨 `await` 或调用外部系统。
