# VM 标定清单

> 每台采集 VM 一行。标定方法见 `坑位手册.md` §1.2/1.3。**凭据不填这里。**
> `vm_instance_id` 必须全局唯一（链接克隆最易犯错，见 `坑位手册.md` §2.4）。

---

## 二、Ubuntu 宿主（KVM/libvirt）· 4 台在运行

镜像：`/var/lib/libvirt/images/win10-01.qcow2` 为基础镜像，各台挂 `win10-0X-diff.qcow2` 增量盘（**链接克隆**）。

| # | libvirt 域名 | guest IP | vm_instance_id | chat_icon x,y | entry x,y | 标定 | 接线 | 自启 |
|---|---|---|---|---|---|---|---|---|
| 1 | `win10-01` | 192.168.122.156 | `win10-01` | 40,120 | 167,65 | ☐ | ☐ | ☐ |
| 2 | `win10-02` | 192.168.122.149 | `win10-02` | 40,120 | 167,65 | ☐ | ☐ | ☐ |
| 3 | `win10-03` | 192.168.122.221 | `win10-03` | 40,120 | 167,65 | ☐ | ☐ | ☐ |
| 4 | `win10-04` | 192.168.122.40 | `win10-04` | 40,120 | 167,65 | ☐ | ☐ | ☐ |

坐标列先填 win10-0 实测缺省值（40/120/167/65）；若某台入口打不开再单独标定并更新此表。
IP 为 2026-08-22 DHCP 实测值，不能作为节点身份；运维脚本应以虚拟机名/MAC 查询当前租约后再连接。

## 五、逐台验收清单

- ☐ 微信已登录、常驻不退出
- ☐ Python 依赖齐全（`celery`/`redis` 是接线必需，本地模式不需要）
- ☐ `config.json` 的 `vm_instance_id` 已改成本台唯一值
- ☐ 冷门词（如"月嫂"）能唤起「关键词 - 搜一搜」窗
- ☐ 筛选三项（排序/类型/时间）面包屑显示已生效
- ☐ 跑一轮：日志出现"领取 N 个关键词" → 采集 → "新增 X 条" → 上报成功
- ☐ 看板 `/admin/devices` 能看到本节点在线、有数据落 PG
- ☐ 自动登录 + 禁空闲锁 + 开机自启（重启后自恢复）
