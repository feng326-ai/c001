# 正式公海恢复记录（2026-08-23）

## 结论

正式线索公海为空不是数据库丢失或同步清空，而是 `leads_dashboard.html` 的内联 JavaScript 存在语法错误，导致整段页面逻辑未执行。修复后正式公海已恢复展示，业务数据未做任何修改。

## 故障证据

- 正式 PostgreSQL：`qualified_leads=11832`，其中默认质量口径 `llm_status=done AND has_lead_value=true` 为 7310 条；商机池原始口径为 469 条。
- Nginx：公海列表与统计接口持续返回 HTTP 200，列表响应包含数据。
- Backend 容器内直接执行管理员公海查询：分组、排除个人活动库后返回 `total=396`、首屏 20 条。
- 浏览器控制台：刷新正式 `/admin` 后稳定出现 `SyntaxError: missing ) after argument list`；页面停留在模板初始值，统计为 0、表格为空。
- 定位结果：重复的 `DOMContentLoaded` 监听器漏写 `);`，并错误引用 `switchTab(mode)` 作用域之外的 `mode`。
