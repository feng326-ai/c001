系统设置

配置大模型服务参数与 AI 清洗提示词，保存后自动生效（无需重启容器）。

🔐 API 密钥

支持在此填写密钥（加密思路：仅存服务器本地 secrets.json，不写入配置、不入 git）。也可用服务器环境变量 OPENAI_API_KEY。

密钥仅保存在服务器本地，页面不会回显已保存的密钥明文。DeepSeek 密钥形如 sk-xxxx。

🧽 后台 LLM 清洗

入库时先用规则评分快速判定线索并提升；LLM 清洗在后台异步运行（60s 一轮），补全活动信息与线上投票识别。开启后无需重启容器。

开关会写进 rule_config.json 的 llm.clean_enabled。注意：docker-compose 环境变量的优先级最高，最终生效值以两者或一为准。

🤖 大模型配置

对接 OpenAI 兼容接口（WebAI2API / DeepSeek / 通义千问 / OpenAI 等）。

容器内访问宿主机请用 host.docker.internal
可直接输入，或点右侧按钮从服务端拉取可选模型

💬 AI 清洗提示词

控制大模型如何判定线索价值与抽取活动信息，留空则回退到内置默认。

定义 AI 助手的核心职责、判定口径与工作风格
规定模型返回的 JSON 结构字段（修改需谨慎，字段名需与后端解析保持一致）
